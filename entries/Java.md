O Oracle Java é a linguagem de programação e plataforma de desenvolvimento N° 1. Ajuda a reduzir custos, encurtar prazos de desenvolvimento, impulsionar a inovação e melhorar os serviços de aplicações. Com milhões de desenvolvedores executando mais de 73 bilhões de Java Virtual Machines em todo o mundo, o Java continua sendo a plataforma de desenvolvimento preferida de empresas e desenvolvedores.
